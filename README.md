An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## What it is

- **Checklist** of all 55 trophies with their official names, descriptions and grades, progress saved in the browser (localStorage), with export and import.
- **Guides in the entry's own words** for every trophy, each naming its sources (official description, Exophase, PSNProfiles) — no copied guide text.
- **Roadmap** to the platinum in six phases, built from the official descriptions.
- **Missables page**: the 8 trophies that can pass you by, each with the reason and how to get it in time.
- **Next-up planner**: queue trophies in the order you want to play them.
- **Filters** by grade and kind, **search**, and a **spoiler setting** that hides story trophy names until earned.
- Paper and night themes; system fonts only; works fully offline.

GTA VI released 2026-11-19, so no guide here can be play-verified yet — the app says so plainly, and every guide is built from the trophy's official description.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or hand it in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
