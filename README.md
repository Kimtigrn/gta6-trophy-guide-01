Leonida Legend — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with saved progress, export/import, filters by grade, kind and missable, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, a missables page, a Next-up planner, and a full guide with sources for every trophy, written in our own words from the official descriptions. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

GTA VI launched 19 November 2026, so no guide here is play-verified yet — every plan says so plainly and cites its sources (the official trophy description via the Exophase trophy list; PSNProfiles trophy list). Official names, descriptions and grades are shown exactly as PlayStation publishes them. No Rockstar logo or official artwork is used.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the app is plain static files under `app/` (no build step, no network requests). `node main.ts` copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
